# Azure Blob Storage Plugin

`ktestify-plugin-azureblob` is a KTestify plugin that adds Azure Blob Storage steps to your Cucumber scenarios. It allows you to upload blobs as test fixtures or assert that a blob was produced by your pipeline.

:::caution[Work in progress]
This plugin is actively being built. The API surface, step wording, and configuration keys documented here reflect the current implementation and may change before the first stable release.
:::

---

## Maven dependency

```xml
<dependency>
  <groupId>io.github.ktestify</groupId>
  <artifactId>ktestify-plugin-azureblob</artifactId>
  <version>0.0.1-SNAPSHOT</version>
  <scope>test</scope>
</dependency>
```

---

## Configuration

```hocon
ktestify {
  azureblob {
    connection-string = "DefaultEndpointsProtocol=https;AccountName=...;AccountKey=...;EndpointSuffix=core.windows.net"
    # Or use individual settings:
    # account-name = "myaccount"
    # account-key  = "..."
  }
}
```

    ├── config/
    │   └── AzureBlobConfig.java          ← reads HOCON config
    ├── entities/

    └── steps/
